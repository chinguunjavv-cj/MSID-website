# MSID вэбсайтын гарын авлага

Гарын авлагын эх нь **[docs/admin-guide.html](docs/admin-guide.html)** файлд байна.

Уг файлаас хоёр хувилбар үүснэ:

- **PDF** — `npm run guide:pdf` командаар `ГАРЫН-АВЛАГА.pdf` файл шинэчлэгдэнэ.
- **Вэб хувилбар** — тухайн файлыг Artifact болгон нийтэлнэ.

---

*Developer note.* This file used to hold a second, hand-maintained copy of the guide in
Markdown. Both copies then had to be edited together, and within a day they had not
been: the Markdown still told MSID there was no password reset and that the site never
sent email, after both had shipped. A guide that is confidently wrong is worse than no
guide, so the HTML — which is what MSID actually reads, as the PDF and the published
page — is now the only source.
